Here are some **simple and useful VS Code extensions/features** for your Python + FastAPI + Markdown study work:

| Extension / Feature     | Main Use                                       |Shortcut   |
| ----------------------- | ---------------------------------------------- | ------------------------------------ |
| **Bookmarks**           | Mark important lines and jump back to them     | `Ctrl + Alt + K`                     |
| **Python**              | Python IntelliSense, debugging, running Python | `F5` = Debug                         |
| **Pylance**             | Python autocomplete, type checking, errors     | Automatic                            |
| **Black Formatter**     | Automatically formats Python code              | `Shift + Alt + F`                    |
| **Prettier**            | Formats Markdown, JSON, etc.                   | `Shift + Alt + F`                    |
| **GitLens**             | See Git history, authors, changes              | `Ctrl + Shift + G`                   |
| **Markdown All in One** | Markdown shortcuts, TOC, navigation            | `Ctrl + Shift + P` → search Markdown |
| **Error Lens**          | Shows errors/warnings directly beside code     | Automatic                            |
| **Thunder Client**      | Test FastAPI/API endpoints inside VS Code      | Extension UI                         |
| **REST Client**         | Test APIs using `.http` files                  | `Ctrl + Alt + R`                     |

I'd especially recommend these:

**1. Bookmarks** → remember important chapters/lines

```text
Ctrl + Alt + K
```

**2. Markdown All in One** → work comfortably with your long Markdown notes.

**3. Sticky Scroll** → keeps your current heading visible while scrolling.

**4. `Ctrl + Shift + O`** → VS Code's built-in **Go to Symbol**, very useful for jumping between Markdown headings.

**5. `Ctrl + G`** → jump directly to a known line.

```text
Ctrl + G
318
Enter
```

### My minimal setup

You don't need to install everything. For your study project, I'd start with just:

```text
✅ Python
✅ Pylance
✅ Bookmarks
✅ Markdown All in One
✅ Error Lens
```

And use VS Code's built-in:

```text
Ctrl + Shift + O  → Jump between headings
Ctrl + G          → Go to line
Ctrl + F          → Find
Ctrl + H          → Replace
Ctrl + P          → Quickly open a file
Ctrl + Shift + P  → Command Palette
```

That combination is more than enough for a **FastAPI + Python + Markdown study project**.
