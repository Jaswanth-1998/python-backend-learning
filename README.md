## About This Repository

This repository documents my journey toward becoming a professional Python Backend Developer.

It contains Python fundamentals, coding exercises, framework tutorials, backend development concepts, practical projects, interview preparation materials, and development documentation.

The primary objective is to develop strong backend engineering skills through consistent practice, hands-on implementation, debugging, and real-world project development.

Rather than focusing only on writing code, this repository emphasizes understanding how backend applications work, how to design them, how to identify and fix problems, and how to build maintainable software.

## Development Philosophy

The learning process follows a practical engineering workflow:

1. **Learn** – Understand the concept and its fundamentals.
2. **Practice** – Solve problems without depending on ready-made solutions.
3. **Build** – Implement real-world features and applications.
4. **Debug** – Investigate errors and identify root causes.
5. **Refactor** – Improve code quality, readability, and architecture.
6. **Test** – Verify functionality and handle edge cases.
7. **Deploy** – Understand how applications run in production.

The focus is on understanding the reasoning behind the code rather than simply copying and executing examples.

## How to Use This Repository

Clone the repository:

```bash
git clone <repository-url>
```

Navigate into the project:

```bash
cd python-backend-learning
```

Create a virtual environment:

```bash
python -m venv venv
```

Activate the virtual environment:

**Windows:**

```bash
venv\Scripts\activate
```

**Linux / macOS:**

```bash
source venv/bin/activate
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run individual Python exercises:

```bash
python first-program.py
```

For framework applications, follow the instructions provided in their respective project directories.
